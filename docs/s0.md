# S0 interfaces and rules

Implement the supplied skeletons without changing their public signatures.
The supplied components and the required behavior of each method are listed below.
All file paths are relative to the repository root.

## Map and state

`levels/n0.json` is the supplied map. Keep it unchanged. `grid` contains
equal-length strings: `#` is a wall and `.` is floor. `start` and `exit`
give integer coordinates on floor, inside the map; booleans are not coordinates.
The exit position becomes an exit tile when the map is loaded.

`initial_state.json` is the shared public state example. Return dictionaries
and lists containing JSON values, not a JSON string or model objects.
Each snapshot is independent of the live game, including nested lists.
Coordinates start at the top-left: east increases x, south increases y.

## Actions and controls

| Raw key | Action |
| --- | --- |
| Z / z / ArrowUp | north |
| D / d / ArrowRight | east |
| S / s / ArrowDown | south |
| Q / q / ArrowLeft | west |
| Space | wait |
| Escape / :quit | quit |
| Unknown key | None |

Each attempted move, including a blocked move, consumes a turn. Waiting also
consumes a turn; no key, an unknown key and quitting do not. Reaching the exit
sets `status="won"` and `message="Victory!"`. After victory, movement and wait
change nothing; the window remains responsive until quit.

## Renderer

Define the minimal interface that makes both views interchangeable. This is a shared Protocol, not a renderer to instantiate.

Supplied in gridworld/contracts.py. The tutor introduces Protocol; both views follow its three methods.

```python
class Renderer(Protocol):
    def start(self) -> None: ...
    def update_render(self, json_state: JsonState) -> None: ...
    def close(self) -> None: ...
```

- **`start()`**: Prepare the view before the game loop.
- **`update_render(json_state)`**: Display the supplied dictionary without changing the model.
- **`close()`**: Release view resources; a second call does nothing.

## InputSource

Define the input shared by both sources: a raw key or None.

Protocol supplied in gridworld/contracts.py alongside Renderer. This file contains no concrete keyboard input or game rules.

```python
class InputSource(Protocol):
    def read_key(self) -> str | None: ...
```

- **`read_key()`**: Return a raw key or None. Do not translate it into an Action or change the game.

## Tile

Represent a terrain tile. In S0, its kind determines whether it is walkable and whether it is an exit.

Implement in gridworld/models/tile.py. Separate Wall, Floor and Exit classes are not required.

```python
class Tile:
    def __init__(self, kind: TileKind) -> None: ...
    def is_walkable(self) -> bool: ...
    def is_exit(self) -> bool: ...
    def to_state(self) -> TileKind: ...
```

- **`__init__(kind)`**: kind is floor, wall or exit; an unknown kind raises ValueError.
- **`is_walkable() → bool`**: False for wall; True for floor and exit.
- **`is_exit() → bool`**: True only for exit.
- **`to_state() → TileKind`**: Return floor, wall or exit in S0, without terminal characters or image files in the model.

## Level

Load the JSON map, organize its tiles and expose safe grid queries to the engine.

Implement in gridworld/models/level.py with LevelError(ValueError). Keep the supplied levels/n0.json unchanged.

```python
class LevelError(ValueError):
    pass

class Level:
    def __init__(self, data: dict) -> None: ...
    @classmethod
    def load(cls, path: str) -> "Level": ...
    def get_start(self) -> tuple[int, int]: ...
    def get_tile(self, x: int, y: int) -> Tile: ...
    def is_walkable(self, x: int, y: int) -> bool: ...
    def is_exit(self, x: int, y: int) -> bool: ...
    def to_state(self) -> LevelState: ...
```

- **`__init__(data)`**: Validate the map schema, build new tiles and turn the exit cell into Tile('exit'). Raise LevelError for an inconsistent map.
- **`load(path) → Level`**: Read the UTF-8 JSON file, then construct Level. Convert OSError and JSONDecodeError to LevelError with a useful cause.
- **`get_start() → (x, y)`**: Return the start as a tuple of integers, separate from the current player position.
- **`get_tile(x, y) → Tile`**: Return the requested tile. Raise IndexError outside the grid, including negative x or y; do not use implicit Python negative indexing.
- **`is_walkable(x, y) / is_exit(x, y) → bool`**: False outside the grid; otherwise delegate to the corresponding tile.
- **`to_state() → LevelState`**: Return id, width, height and a tiles matrix of normalized kinds. Lists must be independent of the model.

## Player

Store the current player position independently of the map and its representation.

Implement in gridworld/models/player.py.

```python
class Player:
    def __init__(self, x: int, y: int) -> None: ...
    def get_position(self) -> tuple[int, int]: ...
    def move_to(self, x: int, y: int) -> None: ...
    def to_state(self) -> EntityState: ...
```

- **`__init__(x, y)`**: Store the initial integer coordinates, excluding booleans. The engine uses Level.get_start().
- **`get_position() → (x, y)`**: Return a tuple without exposing mutable internal data.
- **`move_to(x, y) → None`**: Update coordinates after Engine has validated the move. Do not access Level.
- **`to_state() → EntityState`**: Return a new dict with exactly id=player-1, kind=player, x, y and appearance=player. Do not expose mutable references to the model.

## Engine

Own the game, apply its rules and connect controller and view by delegation, without mixing their implementations.

Implement in gridworld/engine.py. Public methods and their behavior are required; private attributes and helpers are up to you.

```python
class Engine:
    def __init__(self, level: Level, controller: Controller,
                 renderer: Renderer) -> None: ...
    def get_action(self) -> Action | None: ...
    def apply_action(self, action: Action) -> None: ...
    def get_state(self) -> JsonState: ...
    def render(self, json_state: JsonState) -> None: ...
    def run(self) -> None: ...
```

- **`__init__(level, controller, renderer)`**: Create Player at the start; initialize playing, turn 0, an empty message and empty extras. Do not start the view or render in the constructor.
- **`get_action() → Action | None`**: Call controller.get_action once and return its result. No game rules here.
- **`apply_action(action) → None`**: For a supported action, handle movement or waiting, turn counting and victory. quit requests shutdown without changing game state. An unsupported action raises ValueError before any mutation.
- **`get_state() → JsonState`**: Create an independent JsonState with all eight fields, including level, entities, player_id, status, turn, message, interaction=None and extras={}. The player is last. Do not read input or advance a turn.
- **`render(json_state) → None`**: Call renderer.update_render(json_state) exactly once. Do not replace the argument by a get_state call or encode it as a JSON string.
- **`run() → None`**: Render the initial state, then regularly call get_action, apply actions and render the result. None consumes no turn. After victory, keep the display and read until quit. Startup and cleanup belong to the launcher.

## Controller

Read a key through InputSource, then translate it into a game action.

Implement in gridworld/controllers/controller.py. Receives TerminalInput or PygameInput; does not know any concrete view.

```python
class Controller:
    def __init__(self, input_source: InputSource) -> None: ...
    def key_to_action(self, key: str) -> Action | None: ...
    def get_action(self) -> Action | None: ...
```

- **`__init__(input_source)`**: Store the supplied input source without reading a key.
- **`key_to_action(key)`**: z/Z/ArrowUp → north; d/D/ArrowRight → east; s/S/ArrowDown → south; q/Q/ArrowLeft → west; space → wait; Escape or :quit → quit. Unknown keys produce None.
- **`get_action()`**: Call input_source.read_key once. Preserve None; otherwise translate the key.

## TerminalInput

Encapsulate terminal input without translating commands into actions.

Implement in gridworld/controllers/terminal_input.py. One method is sufficient; no specific constructor is needed.

```python
class TerminalInput:
    def read_key(self) -> str | None: ...
```

- **`read_key()`**: Read with input() and Enter; preserve the space used for wait. Return :quit on EOF or interruption.

## BashRender

Build a text representation from the state and pass it to the supplied refresh method to replace the display.

refresh(text) is supplied and must remain unchanged. Implement the minimal constructor, start, state_to_string, update_render and close in gridworld/views/bash_render.py.

```python
class BashRender:
    def __init__(self) -> None: ...
    def start(self) -> None: ...
    def state_to_string(self, json_state: JsonState) -> str: ...
    def refresh(self, text: str) -> None: ...  # SUPPLIED
    def update_render(self, json_state: JsonState) -> None: ...
    def close(self) -> None: ...
```

- **`__init__(), start(), close()`**: A minimal no-op implementation is sufficient. close must be idempotent.
- **`state_to_string(json_state)`**: Convert terrain to characters: floor=., wall=#, exit=E. Overlay entities in order: player=P; unknown appearance=?. Add Turn: N and the message. Return a string without printing or mutation.
- **`refresh(text) — supplied`**: Replace the terminal display. Keep this method unchanged.
- **`update_render(json_state)`**: Call state_to_string then refresh, exactly once each.

## PygameRender

Display the same state in a Pygame window without changing the game rules.

Fully supplied in gridworld/views/pygame_render.py, including sprites. Import it; students do not need to open or edit this file.

```python
class PygameRender:
    def __init__(self) -> None: ...
    def start(self) -> None: ...
    def update_render(self, json_state: JsonState) -> None: ...
    def close(self) -> None: ...
```

- **`start(), update_render(state), close()`**: Follow the same Renderer Protocol as BashRender. Calls stay on the main thread. update_render keeps a copy of the state, then displays it.

## PygameInput

Read window events and return a raw key or None.

Fully supplied in gridworld/controllers/pygame_input.py. The window connection stays inside the two supplied Pygame components; students do not need to open them.

```python
class PygameInput:
    def __init__(self, renderer: PygameRender) -> None: ...
    def read_key(self) -> str | None: ...
```

- **`__init__(renderer)`**: Associate the input source with the supplied window. Pass this source, never the renderer, to the controller.
- **`read_key()`**: Read at most one key; return None without an event and Escape for the window close button. Keep the window responsive, limit polling to 60 reads per second and do not advance the game. Call after renderer.start(), on the main thread.
